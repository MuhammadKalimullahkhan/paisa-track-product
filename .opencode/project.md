# Project Overview

**Project Name:** Paisa  
**Type:** Full-stack financial tracking web application (PWA)  
**Purpose:** Personal finance management dashboard for tracking customers, products, orders, and revenue

## Technology Stack
- **Frontend:** React 19, React Router DOM 7
- **Build:** Vite 6, TypeScript 5.8
- **Styling:** Tailwind CSS 4, Motion (Framer Motion), Lucide Icons
- **Backend:** Express 4, better-sqlite3 (SQLite)
- **Mobile:** Capacitor 8 (Android)
- **AI:** Google Gemini SDK

## Key Files
- Entry: `src/main.tsx`, `server.ts`
- Routes: `src/App.tsx`
- API Client: `src/services/api.ts`
- Types: `src/types.ts`

## Database
- SQLite: `data.db`
- Tables: customers, products, variants, orders
